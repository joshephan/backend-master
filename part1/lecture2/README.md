## 실습 자료

### 준비

이번 강의 실습 자료는 코드가 아니라 문서 세 개다. 예매 서버 저장소에 `docs/` 폴더를 만들고 목록마다 파일을 하나씩 둔다. 설치할 것은 없다.

```text
ticketing/
└── docs/
    ├── contention.md       동시 요청이 부딪히는 곳
    ├── external-calls.md   외부 호출과 실패 시 동작
    └── resource-limits.md  자원 한도
```

### 코드

| 파일 | 내용 |
|---|---|
| [code/docs/contention.md](code/docs/contention.md) | 동시 요청이 부딪히는 곳: 같은 좌석, 남은 좌석 수, 같은 고객의 결제 |
| [code/docs/external-calls.md](code/docs/external-calls.md) | 외부 호출과 실패 시 동작: 결제사, 외부 인증 서버(소셜 로그인), 문자 발송사 |
| [code/docs/resource-limits.md](code/docs/resource-limits.md) | 자원 한도: 커넥션 풀, 결제사 처리량, 문자 발송, 서버 메모리 |

### 해 볼 때 참고

- 세 목록은 로컬 개발에서 맞던 감각이 깨지는 곳과 겹친다. 동시 요청이 부딪히는 곳은 "요청은 하나씩 온다", 외부 호출과 실패 시 동작은 "네트워크는 늘 답한다"가 깨지는 곳이고, 자원 한도는 내 노트북에서 한 번도 닿아 본 적 없는 숫자다
- "막는 방법", "실패 시 동작" 칸은 비워 둔 첫 버전이다. 기능이 늘 때마다 줄을 더한다(인증을 붙이면 인증 서버 호출, 캐시를 붙이면 캐시 서버 메모리)
- 한도 칸의 숫자는 모두 계산용 가정값이다. 자기 서비스의 실제 값으로 바꿔 적는다
