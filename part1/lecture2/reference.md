# 2강 출처

## 도구와 실행 환경

이번 강의는 실행하는 코드가 없다. 실습 자료의 숫자는 모두 계산용 가정값이다.

## 데이터 출처

| 항목 | 출처 | 기준일 |
|---|---|---|
| 좌석 수, 접속자 수, 초당 요청, 결제사·문자 처리량, 요청당 메모리, 서버 메모리 | 강의용 가정. 실제 예매처 수치를 쓰지 않음 | - |

## 참고 자료

이번 강의는 특정 도구나 API의 문서를 따르지 않는다. 실패 응답에 쓰는 HTTP 상태 코드는 아래 문서에 정의되어 있다.

- RFC 9110, HTTP Semantics: https://www.rfc-editor.org/rfc/rfc9110
